# не создаёт ни одна миграция репозитория.

# Зачем файл. Проверка schema-drift сравнивает рабочую базу с той, что
# собирается из миграций. Если ронять проверку на давнем долге, она будет
# красной всегда. Красная всегда — значит её перестанут читать, а это ровно
# та болезнь, от которой проверка и заводится.
#
# Поэтому: проверка падает только на НОВОМ расхождении, сверх этого списка.
# По мере того как долг закрывается миграциями, строки отсюда удаляются.
#

#   • 174 — снято 12.09.2026, когда проверка завелась;
#   • 130 — после того как 11 объектов описали миграцией
#     20260912170000_describe_undocumented_objects_part1.sql;
#   • 57 — после того как 7 пустых объектов удалила миграция
#     20260912180000_drop_unused_empty_tables.sql. 73 строки списка

#
