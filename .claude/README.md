# Права Claude Code в этом репозитории

## Зачем это нужно

Без файла прав Claude спрашивает подтверждение почти на каждое действие: отдельно
на `git commit`, отдельно на `pnpm build`, отдельно на каждый запрос к Supabase.
В мобильном приложении кнопки «разрешить всё» нет — только «Allow once», поэтому
подтверждать приходится десятки раз за сессию.

Файл прав снимает эту рутину, но не открывает всё подряд: опасное по-прежнему
спрашивает или запрещено совсем.

## Как включить

Файл `settings.json.example` **не работает**, пока называется так. Claude читает
только `settings.json` и `settings.local.json`.

Чтобы включить — переименовать:

```
.claude/settings.json.example  →  .claude/settings.json
```

С телефона это делается на GitHub: открыть файл → карандаш (Edit) → в поле имени
убрать `.example` → Commit changes в `main`.

Правила подхватятся со **следующей** сессии: текущая уже запущена со старыми.

## Что разрешено

- чтение и правка файлов в репозитории;
- git: статус, диффы, коммиты, ветки, push **только в ветки `claude/`**;
- сборка и проверки: `pnpm build`, `typecheck`, `lint`, `prettier`, `eslint`;
- Supabase MCP: запросы, миграции, деплой Edge Functions;
- GitHub MCP: создание, чтение и мерж PR.

## Что запрещено — даже с этим файлом

| Запрет | Почему |
|---|---|
| `git push --force`, `push -f` | переписывает историю, потерянное не вернуть |
| `git push origin main` | в `main` только через PR |
| `git reset --hard` | стирает несохранённую работу |
| `rm -rf` | необратимо |
| `curl`, `wget` | произвольные сетевые запросы мимо официальных API |
| `supabase secrets` | доступ к секретам |
| чтение `.env` | там ключи |

Это совпадает с `tasks/rules.md` §9 «Что НЕ делаю автономно».

## Чего файл не отменяет

Вопросы по существу. Архитектурные решения — новая схема БД, новый поток данных,
смена формулы P&L — Claude по-прежнему выносит владелице (`tasks/rules.md` §13).
Это не про технические разрешения, а про то, что решение стоит денег или данных.

## Почему файл создан под другим именем

Файл выдаёт Claude права. Claude не должен включать себе разрешения сам —
поэтому он готовит файл, а активирует его человек одним осознанным действием.
