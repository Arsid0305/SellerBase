## Открытые вопросы

1. **Мячи массажные, 19 SKU.** При текущих карточках код 9019, маркировка с 01.10.2026.
   Переход в 9506 91 900 0 возможен только с полной переделкой: предмет WB на спортивный,
   название без слова «массажный», описание без медицинских формулировок, ДС на спортинвентарь.
   Решать до закупки.
2. **Консервный нож.** Код 8210 применим, если у открывалки механический привод —
   вороток, шестерни, режущее колесо. Проверить конструкцию.
3. **Бандаж чёрный.** У изделия серая вставка. Если это силиконовая полоса на лайкровой
   основе — код 6307 90 100 0 остаётся. Запросить состав у поставщика.
4. **Проект ПП по товарам для дома** — мониторить подписание. Затрагивает ножи для пиццы,
   шпатели и, при коде 3924, таблетницы.
