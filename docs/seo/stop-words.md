# Словарь стоп-слов в карточках товаров

> Обновлено 2026-08-20. Машиночитаемая версия — `scan-stop-words.sql`.
> Методика и шкала риска — `../SEO_MARKETPLACES.md` §6.
> Коды и сроки маркировки — `../marking/codes-marking.md`.

**Важно:** формулировка в описании не создаёт обязанность маркировки. Обязанность
возникает из кода ТН ВЭД / ОКПД 2 и объективных характеристик товара. Слово работает
как довод против собственного кода при споре о классификации, как расхождение
с декларацией соответствия, как заявление о лечебных свойствах без РУ и как сигнал
алгоритмам площадки классифицировать карточку в чужую категорию.

---

## 🔴 Высокий риск

Слово описывает признак, который реально меняет классификацию или требует другого допуска.

| Слово / фраза | Куда ведёт | Чем заменить |
|---|---|---|
| лечебный, профилактический массаж | Реклама и допуск: лечебные свойства без РУ, ст. 24 ФЗ «О рекламе» | «проработка мышц после нагрузки» |
| логопедический массаж | То же | удалить |
| при плоскостопии, ортопедических особенностях | Медицинское показание без РУ, довод за 9021 | «для проработки стоп» |
| медицинские противопоказания, беременность, проблемы с кровообращением | Блок противопоказаний — атрибут медизделия | удалить блок целиком |
| для новорождённых, для малышей | ТР ТС 008/2011: требует ДС на игрушки | удалить |
| компрессионное воздействие | Конструктивный признак позиции 6212, легпром, КИЗ | «деликатная фиксация», если поддержки по конструкции нет |
| с зубной щёткой внутри | Позиция 9603 21, маркировка с 01.10.2026 | «с рельефными щетинками для ухода за зубами» |
| от бруксизма, стоматологическая | Позиция 9021 21, медизделие | не добавлять |

## 🟠 Средний риск

Код не меняется, но слово даёт довод против классификации и тянет алгоритмы площадки
в чужую категорию.

| Слово / фраза | Куда ведёт | Чем заменить |
|---|---|---|
| детский, для детей, для подростков | Довод за 9503, чужая категория выдачи | убрать, оставить взрослое позиционирование |
| мелкая моторика, сенсорные игры | Лексика детских развивающих товаров | удалить |
| игрушка, полезная игрушка | Размывает предмет карточки | «тренажёр», «инвентарь» |
| реабилитация | Довод за 9019 или медицинское назначение | «восстановление после нагрузки» |
| массажёр, микромассаж, массажирует, акупунктурный массаж | Довод за 9019 | «мягкое воздействие рельефа», «точечное воздействие» |
| медицинский аксессуар, медицинская коробка | Приглашает вопрос о группе «Медизделия» | «аксессуар для хранения лекарств», «контейнер-органайзер» |
| утягивающий, корректирующий, корсет | Признаки позиции 6212 | не добавлять |
| чехол, чехол для обуви | Терминология позиции 4202 | «мешок», «мешок для стирки обуви» |
| салфетка, тряпка, для уборки | Позиция 6307 10, в эксперименте ПП 1458 | не добавлять |
| кухонное оборудование, кухонная принадлежность, посуда | Наименование группы перечня ПП 1458 | «аксессуары для вина» — для пробок |

## 🟢 Нейтрально и рабочие ключи

Ложные срабатывания сканера — оставить как есть.

| Слово / фраза | Почему не риск |
|---|---|
| для детской одежды, вещей новорождённого, детский лагерь (в мешках для стирки) | Описывает, ЧТО стирают, а не для кого товар |
| хранить в недоступном для детей месте | Предупреждение по безопасности |
| мойте с детским мылом | Инструкция по уходу |
| в посудомоечной машине | Способ ухода, не назначение |
| эффект массажа (в товарах для животных) | Позиция 9019 относится к механотерапии для человека |

Рабочие ключи — их отсутствие тоже дефект.

| Ключ | Что удерживает |
|---|---|
| МФР, миофасциальный релиз, фитнес, йога, пилатес | Позицию 9506 91 для спортинвентаря |
| спортивная, взрослая, кроссфит, бокс | Отсечку от 9503 в скакалках |
| для собак, для щенков, порода | Исключение из 9503 по прим. 5 к гр. 95 |
| органайзер, контейнер, бокс для лекарств | Аргумент за 3926 против 3924 в таблетницах |
| боксёрская, для единоборств | Позицию 9506 99 в капах |
| механический, вороток, шестерни | Позицию 8210, которой нет в перечне ПП 1458 |

## Найдено в текущем каталоге (аудит 2026-08-20)

80 карточек, 121 находка: 35 высокого риска, 86 среднего.

Основные узлы:

- **Мячи массажные, 19 SKU** — детские и медицинские формулировки одновременно
- **Скакалки, 4 SKU** — противоречие «спортивная взрослая» в заголовке и «детская» в описании
- **Таблетницы, 10 SKU** — «медицинский аксессуар», «в которой находятся медицинские изделия»
- **Мешки для стирки, 8 SKU** — «чехол» как синоним мешка
- **Бандажи, 3 SKU** — «массажёр для лица», «компрессионное воздействие»
- **Игрушка-палочка для собак, 1 SKU** — «с зубной щёткой внутри»
