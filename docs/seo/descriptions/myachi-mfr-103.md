## Главная находка: наименование ведёт не туда, где покупают

Во всех четырёх стоит одно и то же: `Массажный мяч мфр для йоги - фитнеса
пилатеса гимнастики`. Слова «йога», «фитнес», «пилатес», «гимнастика»
занимают 40 знаков из 56.

**Ни по одному из них нет ни единого заказа за год.**

## Эвирма 27.08: ниша «жёсткий» пуста

Топ-14 запроса `мяч массажный` — **100 % реклама**, и все заголовки
одинаковые: «Мяч массажный для мфр массажа», «Мячик массажный».

| | значение |
|---|---|
| реклама в топ-14 | 14 из 14 |
| цены | 160–403 ₽ |
| отзывов у лидеров | 1 713 · 15 463 · 18 116 |

**Ни один конкурент в топе не пишет «жёсткий», «твёрдый» или «гладкий».**
Все продают «мяч для мфр» вообще. При этом жёсткость — первое, что выбирают:
мягкий мяч для проработки не годится, а по внешнему виду её не определить.

Ниша по этим словам свободна, и у нас в ней позиции 4–12 без всякой рекламы.
