## Три источника: мы в чужой нише

### Джем — заказы идут не туда, куда ведёт наименование

| запрос | показов | позиция | заказов | конверсия |
|---|---|---|---|---|
| **скребок для теста** | 12 980 | 18 | **18** | 45 % |
| скребок для теста пластиковый | 7 642 | 37 | 4 | 44 % |
| скребок для выпечки | 275 | 13 | 2 | 33 % |

Все заказы карточки — по слову «скребок». Оно стоит в наименовании вторым,
после «шпателя».

### Эвирма 03.09 — по «шпателю кондитерскому» продаётся другой товар

В топ-20 запроса `шпатель кондитерский` — палетки и лопатки для крема:
«для торта», «палетка изогнутая», «с размерной линейкой», «набор мастихинов».
Скребок для теста там один, на пятом месте, и стоит 168 ₽.

| | значение |
|---|---|
| реклама в топ-100 | 11 % |
| органики в топ-20 | 10 из 20 |
| коридор цен топ-20 | 91–1 559 ₽, медиана 282 ₽ |
| **наша цена** | **1 083 ₽** |

Ниша доступная — органики половина выдачи, рекламы мало. Но это ниша
инструмента для крема, а у нас инструмент для теста. Заходить туда
наименованием — то же самое, что было с «мячами для собак».

### Промопульт — ядро привязано мимо

К карточке привязаны два кластера: `шпатель кондитерский` 29 285
и `кондитерский набор` 24 228. Запроса `скребок для теста`, дающего
все заказы, среди них **нет**.

## Решения

### Наименование

Сейчас: `Шпатель скребок кондитерский для теста` — 38 знаков.

Предлагается: `Скребок для теста и шпатель кондитерский набор 2 шт` — 51 знак.

Обоснование: «скребок для теста» выходит вперёд как запрос, приносящий
100 % заказов; «шпатель кондитерский» сохранён — он остаётся ВЧ-запросом
предмета и привязан в Промопульте; «набор 2 шт» отвечает на то, что видно
на главном слайде и чего нет ни у одного конкурента в топ-5 по скребкам.

### Значения полей

| поле | значение | почему |
|---|---|---|
| **Материал изделия** | `нержавеющая сталь;пищевой пластик` | в кабинете у `101YL` стоит «пластик;метал» — опечатка и потеря слова «нержавеющая», которое есть на слайде |
| **Комплектация** | `Скребок для теста пластиковый - 1 шт.;Нож-шпатель металлический с таблицей мер - 1 шт.` | сейчас «Шпатель кондитерский - 1 шт.;Скребок для теста - 1 шт.» — не сказано, что металлический предмет несёт шкалу |
| Высота предмета | 11 — стоит верно | металлический 11,3 см, округление кабинета |
| Ширина предмета | 15 — стоит верно | совпадает со слайдом |
| Количество предметов в упаковке | 2 шт. — стоит верно | |
| Особенности посуды | `лопатка;нож в комплекте;набор` — стоит верно | |
| Цвет | `желтый;сталь` — стоит верно | |
| **Упаковка** | `картонная коробка` | поле пустое, на слайде коробка DOUGH SCRAPER |

### Описание

У `101YL` в кабинете 688 знаков против 1 656 у снятой голубой — вдвое короче
при том же товаре. Пересобрано на 1 400 знаков вокруг скребка, с таблицей мер
как главным отличием.

## Открытые вопросы

1. **Цена 1 083 ₽ против рынка.** В нише скребков прямой аналог на пятом
   месте стоит 168 ₽, медиана топ-20 запроса — 282 ₽. Себестоимость 192 ₽.
   Вопрос к юнит-экономике: есть ли запас, чтобы войти в коридор.
2. **Срез Эвирмы снят не по тому запросу.** Есть `шпатель кондитерский`
   и `шпатель кондитерский металлический`; нужен по `скребок для теста`
   (12 980) — там мы на 18-м месте с конверсией 45 %, и видно, кто рядом.
3. **Привязать `скребок для теста` в Промопульте.** Сейчас к карточке
   привязаны только «шпатель кондитерский» и «кондитерский набор».
4. **Голубая `101BL`** снята с производства — убедиться, что карточка
   скрыта в кабинете, а не просто обнулён остаток.
