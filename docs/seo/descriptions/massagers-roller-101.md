```
Массажер для шеи ручной роликовый ленточный: гибкая лента 110 см, ролики идут по шее и плечам. Давление жёсткое.

Жёсткость высокая
Ролики твёрдые, давление ощутимое. Инструмент для глубокой проработки мышц после дня за компьютером или смены на ногах. Для лёгкого поверхностного массажа не подходит.

Достаёт до участков, недоступных руке

Широкий захват за один проход
Роликовые узлы расставлены по всей длине ленты. Каждый узел собран из нескольких рельефных роликов, поэтому за одно движение прорабатывается полоса мышц, а не узкая дорожка. По отзывам, ощущение тепла сохраняется долго после сеанса.

Пластик вместо дерева

Складывается вдвое
В сложенном виде 55 см, вес 160 граммов. Помещается в спортивную сумку, рюкзак, чемодан, ящик рабочего стола.

Интенсивность регулируется натяжением
Сильнее натянута лента — проработка глубже, слабее — мягче. Ролики вращаются свободно, скользят по коже гладко. Результат зависит от усилия и регулярности.

В комплекте один массажёр. Бытовой инструмент для самомассажа.
```
