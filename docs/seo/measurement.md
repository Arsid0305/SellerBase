# Замер эффекта пересборки

> Заведено 2026-08-28. Порядок работы, о котором договорились с владелицей:
> выгрузка → разбор по группе → заливка → повторная выгрузка → сравнение.

## Цикл

1. **Выгрузка.** Кабинет → Аналитика → Поисковые запросы, период год,
   фильтр «Заказывали». Файл кладётся в `wb_search_queries` с датами периода.
2. **Разбор по группе.** Отдельно, по одной группе за раз: какие запросы
   привязаны, на каких позициях стоим, где заказы, чего нет в текстах.
3. **Заливка.** Каждая правка отмечается в `wb_card_uploads` — артикул,
   дата, что именно залито (`title`, `fields`, `description`,
   `infographic`, `video`).
4. **Повторная выгрузка** через 4–8 недель, тот же отчёт.
5. **Сравнение** — вид `v_search_query_delta`: новые запросы, выпавшие,
   сдвиг позиции и заказов, и дата заливки рядом.

## Что портит замер и как это обходится

**Сезонность.** «Мешок для стирки пуховика» растёт к зиме сам, «мешок для
стирки обуви» проседает летом. Прямое сравнение двух срезов припишет нам
работу календаря.

Обход: **карточки, ещё не залитые на момент замера, — контрольная группа.**
Их динамика показывает сезонный фон. Наш эффект — разница между
переписанными и непереписанными за тот же период. Ради этого и нужен
`wb_card_uploads`: без даты заливки контрольная группа не определяется.

**Фильтр «Заказывали».** Запрос без единого заказа в выгрузку не попадает.
Поэтому «запроса нет в файле» по-прежнему не значит «спроса нет» — это
третий случай правила метода №2 за одну сессию.

**Реклама.** Позиция по запросу смешивает органику и рекламу. Если ставка
менялась между срезами, сдвиг позиции нельзя приписать тексту. Крупные
изменения рекламы стоит отмечать в `wb_card_uploads` заметкой.

## Что считаем успехом

Не позицию саму по себе, а три вещи по убыванию важности:

1. **Новые запросы, которых не было.** Прямое следствие текста: WB привязал
   кластер, потому что мы его написали.
2. **Рост заказов при неизменной частотности.** Значит текст стал точнее
   попадать в намерение.
3. **Сдвиг позиции** — самый шумный показатель, зависит от цены, остатков,
   рекламы и конкурентов. Читать последним.
