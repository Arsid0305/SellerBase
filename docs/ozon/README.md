# Карточки Ozon — точка входа

Всё про заливку карточек на Ozon начинается отсюда. Правило одной точки входа — `tasks/rules.md` §26.

## Что здесь есть

| Файл | Что это |
|---|---|
| `Озон_рабочая_книга.xlsx` | Рабочая книга: заполняем её, а не шаблоны Ozon |
| `../../scripts/ozon_build_book.py` | Собирает книгу из официальных шаблонов категорий |

## Почему книга одна, а файлов загрузки одиннадцать

Ozon принимает файл **по одной категории**. У наших одиннадцати категорий 93 разных
колонки, общих из них 28. Плюс в каждом шаблоне шесть скрытых страниц со списками
значений и 26 проверок ввода — если склеить книги, всё это умрёт.

Поэтому: работаем в одной книге, файлы загрузки собираются из неё обратно.
Собираются **поверх родного шаблона Ozon**, а не с нуля — проверки и выпадающие
списки остаются живыми.

## Устройство книги

- **Как заполнять** — памятка
- **Товары** — общий список, строка на товар. Артикул связывает с листом категории
- **11 листов по категориям** — только особые характеристики
- **Справочники** — допустимые значения, вытащенные из шаблонов

Шапка красная — без поля Ozon карточку не примет. Жёлтая — артикул и категория.

## Что где заполняется

Обязательных полей немного: на листе «Товары» их 12, на листе категории от 2 до 5.

`ТН ВЭД коды ЕАЭС` и `Тип` лежат **на листах категорий**, хотя есть во всех
шаблонах: список у каждой категории свой (у ТН ВЭД от 34 до 426 значений).
На общем листе к ним не привязать выпадающий список.

`Цвет товара` и `Страна-изготовитель` одинаковы везде — они на листе «Товары».

## Что решает владелица

**Код ТН ВЭД.** Список закрытый, но выбор за ней: Ozon прямо пишет, что при
сомнениях нужно к таможенному представителю, и ответственность на продавце.

## Требования Ozon, которые легко забыть

- **Фото**: только прямые ссылки на картинку (`.jpg`, `.png`) или Яндекс.Диск.
  Главное — одна ссылка, дополнительных до 14 через пробел. Фон белый или светлый.
  Без надписей, цен, логотипов и водяных знаков — за нарушение берут плату.
- **Название товара** можно не заполнять: Ozon соберёт его сам из типа, бренда,
  модели и важных характеристик категории.
- **Хештеги**: до 30 штук, каждый до 30 знаков, слова через нижнее подчёркивание.
  Бренды и название товара в хештеги не идут.

## Пересобрать книгу

Когда Ozon обновит шаблоны — скачать свежие и прогнать:

```bash
python3 scripts/ozon_build_book.py <папка_со_свежими_шаблонами> docs/ozon/Озон_рабочая_книга.xlsx
```

## Заполнение (10.09.2026)

Книга заполнена тем, что уже известно: `scripts/ozon_fill_book.py`.

**Артикулы — из файла владелицы UNIT, лист «Себес».** Это источник истины по
товарам: там связка «Код WB / Код OZON / Арт. Поставщика / Номенклатура /
Штрихкод». База под него подстраивается, а не наоборот.

**Коды ТН ВЭД взяты с WB один в один** — товар тот же, код у него один.
Достаются из `sku_catalog.characteristics` по коду WB. Проверено: все коды с WB
есть в списках Ozon для соответствующих категорий, кроме одного сочетания —
`9506919000` отсутствует в списке категории «Аксессуар для массажа».

Итог: 74 товара, 64 разложены по категориям, 47 кодов ТН ВЭД проставлено.

Габариты и вес переведены из сантиметров и килограммов в миллиметры и граммы —
Ozon хочет так.

### Не заполнено намеренно

- цены и НДС — решение владелицы, не данные;
- фото — Ozon берёт только прямые ссылки, которых у нас пока нет;
- аннотация, хештеги, Rich-контент — отдельная работа по SEO, у Ozon свои правила.

### Требует решения владелицы

- **8 кап** — шаблон категории под них не скачан
- **Чеснокодавка** — то же самое
- **Таблетница круглая 7*2 бел Д** (`ACRA7TB101WH`) — есть в UNIT, нет в базе
- **«Тренажер для кисти»** — шаблон скачан, но товаров под него не нашлось.
  Фитнес-резинки и скакалки отнесены в «Фитнес и йога»; если резинки должны
  идти в «Тренажер для кисти» — переложить.
- **Массажеры** разделены по названию: где «мяч», «мячик», «шарик» — в
  «Спортивный массажный мяч» (18 шт), остальные — в «Аксессуар для массажа» (4 шт).

Список несопоставленных — на листе «Что уточнить» в самой книге.
