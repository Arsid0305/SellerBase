## ⏳ Что зависит от владелицы

1. **Создать Telegram-бота** — `@BotFather` → `/newbot` → `TELEGRAM_BOT_TOKEN`
2. **Узнать `TELEGRAM_CHAT_ID`** — написать боту любое сообщение, `curl https://api.telegram.org/bot$TOKEN/getUpdates`
3. **Установить секреты в Supabase**: `supabase secrets set TELEGRAM_BOT_TOKEN=... TELEGRAM_CHAT_ID=...`
4. **Проверить `WB_TOKEN_READ` в Supabase secrets** — есть ли актуальный, не сгоревший
5. **Включить Environment + Required Reviewer** для `deploy.yml` и `migrate.yml` в Settings → Environments
6. **Передать Excel** «Заказы Китай», «Фулфилмент», «Поставки» для автосебеса (когда будет реализован)
