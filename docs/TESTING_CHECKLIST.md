# Чек-лист тестирования SellerBase

После активации WB Tariffs cron, WB Content sync, расширенных полей расходов, Telegram уведомлений.

Открывать на проде (`seller-base-web.vercel.app`). Идти по приоритету.

---

## 🔴 Приоритет 1 — Главное (твоя боль про маржу)

### Дашборд `/dashboard`
- [ ] Утренний бриф сверху (вчера выручка/прибыль + критичные SKU + аномалии + проблемы)
- [ ] 4 KPI в строку: Доходы / Основные расходы / Доп.расходы / Прибыль с дельтами %
- [ ] Виджет «Логистический пульс» — средний коэф моих складов vs неделю назад
- [ ] График доходы/расходы за период
- [ ] Категории WB — выручка/доля/маржа
- [ ] Баннер аномалий **внизу** (z-score > 2σ)
- [ ] Кнопка «Скачать XLSX» — скачивает шаблон CF/PL с заполненными неделями
- [ ] Период переключается в топбаре, включая пресеты «Полгода»/«Год»

### Поставки `/supplies` (заменяет твой Excel)
- [ ] Список планов поставок с историей
- [ ] Кнопка «Новая поставка» открывает большую таблицу
- [ ] 3 блока: продажи 60д по складам / остатки (WB + Дом + ФФ) / везти
- [ ] Inline-редактирование Дом/ФФ остатков
- [ ] Dropdown выбора поставщика 1688 (если есть)
- [ ] Кнопка «Скачать ФФ-шаблон» — даёт формат `Штрихкод+Количество+Название`
- [ ] Кнопка «Скачать Заказ 1688» — формат `Ссылка+Кол-во+Цена ¥`

### Карточка товара `/products/[barcode]`
- [ ] Реальное фото из WB (после первого WB Content sync)
- [ ] Бейдж lifecycle: LEADER если маржа ≥20% + топ 20% по выручке
- [ ] Размеры (длина/ширина/высота/объём) из UNIT_WB
- [ ] Карточка «Прогноз логистики» — выбор склада + формула WB
- [ ] Поставщики 1688 — список с inline-add/edit/default
- [ ] События: цена изменилась, продажи всплеск/падение, низкий остаток
- [ ] История карточки (versioning из snapshots)
- [ ] Сценарии покупки (если привязаны)

## Что НЕ работает / отложено

- **Реклама** `/ads` — мок, нужны WB Adv API ключи
- **Отзывы** `/reviews` — мок, нужен WB Feedbacks API (есть у твоего ReviewBot)
- **Ozon** — нет данных, нужны Ozon API ключи
- **SEO/Поиск ниши** `/niche` — отдельный блок у тебя
- **Расследования** `/problems` — каркас был, закрыли при чистке (вернём при необходимости)
- **Демо-кнопки** — закрыли при чистке (вернём при необходимости)

2. Telegram бот молчит — проверь `/settings/notifications` подписку
3. Просто скажи «На странице X не работает Y» — починю
