# Как протестировать новые разделы

Прогон после волны PR #47-70. Открывать на проде (seller-base-web.vercel.app) после того как соответствующие PR смержатся.

## Что куда смотреть

### Дашборд `/dashboard`
- [ ] Кнопка «Скачать XLSX» — скачивает файл, открывается в Excel со всеми вкладками. Цифры в `PL WB (нед)` строка 7 заполнены реальными продажами по неделям 2026.
- [ ] Баннер аномалий — внизу страницы (был сверху). Если есть аномалии — ссылки на товары работают.
- [ ] Период-пикер — есть пресеты «Полгода» и «Год».

### Каталог `/products`
- [ ] Колонка «Состояние» с цветным бейджем lifecycle (NEW/LEADER/STABLE/...).
- [ ] Колонка «Видимость / Доверие / Ценность» — 3 прогресс-бара.
- [ ] Состояние читается из SQL view `v_sku_lifecycle` (после мерджа #62 — быстрее загрузка).

### Карточка товара `/products/[barcode]`
- [ ] **Фото товара** в правом верху (после применения cron WB Content) — пока pure placeholder если cron ещё не пробежал.
- [ ] **Бейдж жизненного цикла** в карточке «Товар».
- [ ] **Карточка «События»** — резкие изменения цены/продаж/остатков за 30 дней.
- [ ] **Карточка «История»** — если есть снимки за 30 дней (backfill уже сделан → должны быть).
- [ ] **Карточка «Покрываемые сценарии»** — после привязки товара к сценариям через `/customers` или Демо-кнопки.

### Себестоимость `/products/costs`
- [ ] Inline-редактирование cost у каждого SKU.
- [ ] Кнопка «Импорт CSV» (формат: `barcode;cost;valid_from`).
- [ ] Модалка «История» по строке — показывает версии cost.

### Цели `/goals`
- [ ] Кнопка «Заполнить демо» создаёт 3 примера: «Выручка > 1М», «Маржа > 25%», «10 новых SKU».
- [ ] Прогресс-бар, бейдж статуса, модалка редактирования.
- [ ] «Очистить демо» удаляет помеченные `source='demo'`.

### Задачи `/tasks`
- [ ] Канбан 4 колонки (Todo / В работе / Готово / Отменено) на десктопе.
- [ ] На мобиле — фильтр-чипы.
- [ ] Демо: 5 задач, привязаны к цели «Выручка > 1М», к SKU.
- [ ] Квик-действия «→ В работе» / «✓ Готово».

### Проблемы `/problems`
- [ ] Список карточек проблем. Severity-бейдж (low/med/high/critical).
- [ ] Демо: 2 проблемы — CTR упал, возвраты выросли.
- [ ] Клик → `/problems/[id]` — investigation board (Расследования → Причины → Гипотезы).

### Знания `/knowledge`
- [ ] Лента подтверждённых выводов из гипотез. Если ничего не подтверждено — пусто.

### Покупатели `/customers`
- [ ] Демо: 2 персоны (мама, спортсмен), 3 сценария (подарок, спонтан, замена).
- [ ] Клик на персону → её сценарии.
- [ ] Клик на сценарий → связанные персоны + товары.

### Снимок бизнеса `/snapshot`
- [ ] Выбор даты — открывает `/snapshot/2026-05-20` (например).
- [ ] KPI на ту дату, открытые цели/задачи/проблемы на ту дату, аномалии и топ-10 SKU.
- [ ] Навигация «← пред / след →» работает.

### Pareto 80/20 `/analytics/pareto`
- [ ] 3 KPI: «X% SKU даёт Y%», SKU в зоне A, средняя выручка зоны A.
- [ ] Кривая Парето с reference-линиями 80% и 95%.
- [ ] Таблица с зонами (бейджи A/B/C), CSV экспорт.

### Сравнение периодов `/compare`
- [ ] DualPeriodPicker (Период A + Период B).
- [ ] Таблица сравнения KPI с дельтами и стрелками.
- [ ] Двойной график выручки (sky / emerald).
- [ ] Топ-5 роста и топ-5 падения SKU.

### Здоровье `/health`
- [ ] Когда последний раз тянули stocks/reports.
- [ ] Кол-во активных SKU, SKU без cost.
- [ ] Снимки за сегодня, активные цели, открытые задачи.

### Глобальный поиск (Cmd+K)
- [ ] В топбаре кнопка с шорткатом. Открывает модальное окно.
- [ ] Поиск по товарам / целям / задачам с подсветкой совпадений.

### Мобильная вёрстка
- [ ] Гамбургер в топбаре открывает drawer.
- [ ] Таблицы скроллятся горизонтально.
- [ ] Все 3 grid'а KPI на мобиле = 1 колонка.

### PWA на телефоне
- [ ] iOS Safari → «Поделиться → На экран Домой» → иконка SB на тёмном фоне с зелёной точкой.
- [ ] Android Chrome → «Установить приложение» → то же.
- [ ] Открывается в standalone (без браузерной обвязки).
