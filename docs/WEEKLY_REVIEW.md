## Как читается строка

Каждый показатель в снимке идёт не одним числом, а строкой:

```
текущая неделя → прошлая → Δ% → среднее за 4 недели → порог → статус → причина
```

Основание для этого уже есть: таблица недельных метрик по SKU заполнена
с 1-й недели 2026 года по 37-ю - 37 недель, 68 товаров. То есть и «прошлая
неделя», и «среднее за 4 недели» берутся из готового, считать с нуля не надо.
